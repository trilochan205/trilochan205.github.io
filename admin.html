Token बनाउने तरिका:
  1. GitHub मा Fine-grained token बनाउनुहोस्।
  2. Resource owner: trilochan205 र Repository access: Only select repositories → trilochan205.github.io छान्नुहोस्।
  3. Repository permissions मा Contents → Read and write मात्र दिनुहोस्।
  4. Generate गरेर token यहाँ paste गर्नुहोस्। Token मलाई वा अरू कसैलाई नपठाउनुहोस्।
