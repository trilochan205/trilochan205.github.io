# Bato Mero Android app

This repository builds an installable Android debug APK using Capacitor.

- App name: Bato Mero
- Android application ID: com.trilochansubedi.app
- Website: https://trilochan205.github.io
- Offline support: provided by the website service worker after the app has loaded while online once.

## Build APK

Open the repository's **Actions** tab, select **Build Bato Mero Android APK**, and choose **Run workflow**. When the run completes, download the `Bato-Mero-Android-APK` artifact and extract `app-debug.apk`.

This debug APK is directly installable on Android. It is not a Play Store release build.
